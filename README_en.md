# Kaula Language Support for VS Code

[中文文档](README.md) | [Detailed Docs](docs/README.md)

## Overview

**Kaula Language** is a VS Code extension that provides comprehensive language support for the **Kaula** programming language. Kaula is a high-performance systems programming language featuring a unique **SOR (Scoped Ownership Release)** paradigm that guarantees memory safety at compile time while delivering superior performance and memory efficiency compared to traditional approaches.

## Features

### Language Basics
- **Syntax Highlighting** — Full TextMate grammar support for Kaula core language and SOR extension syntax
- **Language Configuration** — Bracket matching, auto-closing pairs, `//` and `#` comment toggling, code folding
- **Code Snippets** — Pre-built snippets for SOR functions, `task()`/`async()` parameters, and standard library imports

### Smart Editing
- **Standard Library Auto-Completion** — IntelliSense suggestions for `std.module.func` patterns
- **Type Hints** — Hover tooltips showing variable/function types, `auto` inference, and signature help
- **Code Formatting** — Integrated `kaulafmt` tool (`Shift+Alt+F`)
- **SOR DAG Diagnostics** — Visual ownership release dependency graph, detecting circular dependencies and use-after-move
- **Compiler Static Analysis** — Deep error diagnostics via `kaulac --check`

### Navigation & Refactoring
- **Go to Definition** — `F12` to jump to variable/function declarations
- **Find References** — `Shift+F12` to find all references
- **Document Symbols** — Outline panel showing `fn`/`struct`/`class`/`interface` etc.
- **Rename Symbol** — `F2` to rename and update all references

### Build Integration
- **Build/Run** — `Kaula: Build` and `Kaula: Run` commands
- **SOR Mode** — Optional `--sor` compile-time ownership analysis

### Source Mapping (KL ↔ C)
- **Source Map Generation** — `.map.json` file generated by default during compilation
- **Split Mapping View** — Side-by-side KL and C code with corresponding line highlighting
- **Synchronized Scrolling** — Cursor movement auto-scrolls the other side
- **Bidirectional Jump** — `F12` in C files jumps to KL source; command jumps to C code

## SOR Paradigm

The **SOR (Scoped Ownership Release)** subsystem is Kaula's flagship feature:

- **Compile-time ownership safety** — All ownership transfers are verified during compilation
- **Zero-copy semantics** — Smart pointer/reference decisions eliminate unnecessary data copies
- **Function-level `#[sor]` annotation** — Opt into SOR analysis per function for fine-grained control
- **Enhanced static analysis** — Intelligent compile-time information including liveness analysis, escape analysis, and inter-procedural analysis
- **Performance gains** — In many scenarios, SOR outperforms traditional memory management in both speed and memory efficiency

## Commands

All commands are under the `Kaula` category, accessible via `Ctrl+Shift+P`.

| Command | Description |
|---|---|
| `Kaula: Build Kaula File` | Compile current file |
| `Kaula: Build and Run Kaula File` | Compile and run |
| `Kaula: Show Source Mapping View (KL vs C)` | Open split mapping view |
| `Kaula: Toggle Sync Scroll in Mapping View` | Toggle synchronized scrolling |
| `Kaula: Jump to Kaula Source (from C)` | C → KL jump |
| `Kaula: Jump to Generated C Code` | KL → C jump |

See [Commands Reference](docs/02-commands.md) for details.

## Configuration

| Setting | Type | Default | Description |
|---|---|---|---|
| `kaula.build.kaulacPath` | string | `""` | Path to `kaulac` compiler executable |
| `kaula.build.sor` | boolean | `false` | Enable SOR analysis during build |
| `kaula.build.sourceMap` | boolean | `true` | Generate source map file during build |
| `kaula.format.kaulafmtPath` | string | `""` | Path to `kaulafmt` formatter executable |
| `kaula.mapping.syncScroll` | boolean | `true` | Enable synchronized scrolling in mapping view |
| `kaula.sorDiagnostics.enable` | boolean | `true` | Enable Release DAG dependency diagnostics |

See [Configuration Docs](docs/03-configuration.md) for details.

## Requirements

- VS Code **1.75.0** or higher
- Kaula compiler (`kaulac`) and formatter (`kaulafmt`) — the extension auto-discovers executables in the Toolkit directory

## Installation

1. Open VS Code
2. Go to **Extensions** (`Ctrl+Shift+X`)
3. Search for **"Kaula Language"**
4. Click **Install**

Alternatively, install from a `.vsix` file:
```bash
code --install-extension kaula-language-0.1.0.vsix
```
